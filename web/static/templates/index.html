API Documentation
Job Details

Picks proven defaults for a whole job type (JSON output keeps the status and owner fields). Every field stays freely editable afterwards.

Selecting a template appends its keywords only — no other setting changes. “Apply template defaults” additionally sets that template’s recommended settings (JSON, depth 10, emails on, 90m, concurrency 2, reviews count-only).

JSON preserves fields the CSV export flattens or drops.

Location Settings

Applies only when coordinates are set.

Leave latitude and longitude empty to search without a map anchor.

Grid mode sweeps a bounding box cell by cell. Faster via the CLI for very large areas; not available with Fast Mode.

Advanced Options

Applies only in Fast Mode.

Fast Mode is quicker but collects less data — fields such as status and owner are at risk of being empty.

Proxies

Examples:

HTTPS proxy with username/password: https://username:password@myproxy.local:443

HTTP proxy with username/password: http://username:password@myproxy.local:443

SOCKS5 proxy without auth: socks5://127.0.0.1:8000
