Google Maps scraper

google_maps

v1 opens Google Maps in a browser, scrolls the list, and reads places and websites several at a time.

v2 reads Google's results 20 at a time without a browser, then visits each website one after another with a fixed gap. Each search has a fixed time limit, so the job can never run longer than searches × that limit.

One search per line, as you would type it into Google Maps.

Every search runs in every place: "dentist" × "Austin TX" becomes "dentist in Austin TX". Leave empty to run the searches as typed.

Map grid: 2,000+ results from one city

Google shows at most ~120 results for a search. The grid runs each search once per square, zoomed in, and keeps each business once. Leave "Where" empty when this is on.

Type a city to see how many squares and searches it makes.

"Results per search" applies to each square; ~20 or ~60 is usually enough. Give a grid job a long "Stop after".

✉ Every listing with a website has all its email addresses collected: from its front page and its own contact, about and team pages.

v2 settings

A search that runs out of its time keeps every place it read; websites it did not reach are marked "skipped_budget". "Stop after" still applies.

Only needed to pin a search to coordinates; "Where" above is usually enough.
