Job Details

Picks proven defaults for a whole job type (JSON output keeps the status and owner fields). Every field stays freely editable afterwards.

Appends a ready-made keyword list on new lines below what you already typed; exact duplicates are skipped.

JSON preserves fields the CSV export flattens or drops.

Location Settings

Leave latitude and longitude empty to search without a map anchor.

Grid mode sweeps a bounding box cell by cell. Faster via the CLI for very large areas; not available with Fast Mode.

Advanced Options

Fast Mode is quicker but collects less data — fields such as status and owner are at risk of being empty.
